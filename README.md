# Kenenisa Beyan - Portfolio

A modern, responsive portfolio website built with React, Tailwind CSS, and Framer Motion. Showcases my skills, projects, freelance experience, and provides multiple ways to connect.

## ✨ Features

- **Dark/Light theme** with persistent user preference
- Smooth animations powered by Framer Motion
- Fully responsive design (mobile, tablet, desktop)
- Sections: Hero, Skills, Projects, Experience, Freelance Highlights, Contact
- Interactive project cards with live demo and code links
- Social media integration (GitHub, LinkedIn, Twitter, etc.)
- Scroll progress indicator
- Loading screen with animated logo
- Scroll-to-top button
- SEO friendly with semantic HTML

## 🛠️ Technologies Used

- **Frontend:** React, Tailwind CSS, Framer Motion
- **Icons:** React Icons (Fa, Si, etc.)
- **Build Tool:** Vite
- **Package Manager:** npm / yarn
- **Deployment:** Vercel / Netlify (choose your platform)

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or later)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/kenenisabeyan/portfolio.git
   cd portfolio
Install dependencies

bash
npm install
# or
yarn install
Start the development server

bash
npm run dev
# or
yarn dev
Open http://localhost:5173 in your browser.

Building for Production
bash
npm run build
# or
yarn build
The output will be in the dist folder, ready to be deployed.
